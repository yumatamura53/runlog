# RunLog — 自分用ランニング記録アプリ

スマホのブラウザで動くランニング計測アプリ（PWA）です。ホーム画面に追加するとアプリのように使えます。
ビルド不要の静的ファイルだけで動きます。

## できること
- GPS で距離・タイム・現在ペース・平均ペース・1km ラップを計測
- 1km ごとの音声読み上げ（タイム・ラップ）
- 一時停止／再開、止まったら自動一時停止（設定でオン）
- 終了は誤タップ防止のため「長押し」
- 走ったルートを地図に表示（OpenStreetMap）
- 記録一覧、今週・今月の合計距離、ラップ表、メモ
- GPX 書き出し（Strava などに取り込み可能）
- 計測中にアプリが落ちても、開き直すと途中から復元

## GPS の精度対策
- 誤差 35m を超える測位は使わない
- 秒速 10m（時速 36km）を超える移動は「GPS の飛び」として除外
- 立ち止まり中の細かい揺れ（数m）は距離に加算しない
- 手動一時停止中に移動した分は距離に含めない

## 使い方（公開）
位置情報は **HTTPS** でしか使えないため、どこかに置いて公開する必要があります（無料でOK）。
- GitHub Pages: このフォルダをリポジトリに置き、Settings → Pages で公開
- Netlify Drop (https://app.netlify.com/drop): フォルダをドラッグ＆ドロップするだけ

iPhone: Safari で開く → 共有 → 「ホーム画面に追加」→ 初回スタート時に位置情報を「許可」

## 制約（ブラウザアプリの限界）
- **画面ロック中・他アプリ表示中は GPS が止まります。** 計測中は画面をつけたままにしてください（自動でスリープは防止します）。
  画面が消えていた区間は、戻ったときに直線距離で補われます（曲がり道では短めになります）。
- 記録はこの端末のブラウザ内に保存されます。Safari の「履歴とWebサイトデータを消去」で消えるので、大事な記録は GPX で書き出してください。
- 心拍計など外部センサーとの連携はできません。

画面ロック中も計測したくなったら、同じロジックで iPhone ネイティブアプリ（Expo / React Native）にする方法もあります。

## ファイル

- `sw.js` — オフライン起動用のキャッシュ
- `vendor/leaflet/` — 地図ライブラリ Leaflet 1.9.4（BSD-2-Clause）
