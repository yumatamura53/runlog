# RunLog — 自分専用のランニング記録アプリ

「開いてすぐ走れる」「計測が正確」「走ったあとの分析が全部無料」を目指した、自分専用のランニングアプリです。
SNS 機能・広告・課金はありません。記録はすべて **自分の端末の中だけ** に保存されます。

- **ブラウザ版**（このフォルダ）: スマホの Safari / Chrome で開いて「ホーム画面に追加」するだけ。インストール不要。
- **ネイティブ版**（`native/`）: 同じアプリを iPhone / Android アプリにしたもの。**画面ロック中も記録できます。** 手順は `native/README.md`。

## できること

### 計測
- 距離・タイム・現在ペース・平均ペース・km ごとのペース、大きな文字で表示
- **GPS の精度対策**（下記）で、ビル街やゆっくりジョグでも距離がずれにくい
- 1km（0.5km / 5分 / 10分）ごとの **音声ガイド**（ラップ・タイム・平均ペース）
- **メニュー**: フリーラン／距離目標（5km・10km など）／時間目標／**インターバル**（400m×8 など、自作も可）／目標ペース
  - 目標の半分・残り 1km・残り 500m、インターバルの開始・終了・「あと10秒」を音声で案内
  - 目標ペースより遅い・速いと音声でお知らせ
- 3 秒カウントダウン、信号待ちで **自動一時停止**
- **画面ロックボタン**: ポケットや手の中での誤タッチ防止（長押しで解除）
- 終了は **長押し**（誤って終わらない）。一時停止中は「記録せずに破棄」も可
- 計測中にアプリが落ちても、開き直すと **続きから再開**

### 記録・分析（Strava の有料機能にあたるものも含めて無料）
- ルート地図（**ペースで色分け** も可）、ペースと標高のグラフ（グラフをなぞると地図上の位置を表示）
- km ごとのラップ（最速ラップに ⚡、km ごとの上り下り）
- **自己ベスト**（1km / 5km / 10km / ハーフ / フル。ラン途中の最速区間から自動で計算）と更新時のお知らせ
- **予想タイム**（直近 90 日のベストから 5km〜フルを予想）
- 週・月の **目標** と達成状況、週ごとの距離グラフ、カレンダー、何週連続で走っているか
- 週の距離を急に増やしすぎたときの、けが予防のひと言
- 種類（ジョグ・ペース走…）、**シューズ**（シューズごとの走行距離）、体感、メモ
- 手入力（トレッドミルなど）、**Strava などの GPX を取り込み**（複数まとめて可）

### 共有・バックアップ
- SNS 用の **共有画像**（地図画像は使わず、ルートの線と数字だけ）
- GPX 書き出し（Strava などへ）
- **プライバシー**: 共有画像と GPX では、スタートとゴール付近（200m / 500m / 1km）を隠せます（自宅の場所が分からないように）
- 全記録のバックアップ・復元（JSON）

## GPS の精度について
スマホの GPS は数 m〜十数 m 揺れるため、点と点の距離をそのまま足すと実際より長くなります（最初の版では 5〜19% 長くなっていました）。
RunLog では次の方法で補正しています。

1. **カルマンフィルタ** で位置の揺れをならす
2. GPS が出す **速度（ドップラー）× 時間** と、位置の移動量を 7:3 で混ぜて距離にする（左右の揺れに強く、端末のくせにも強い）
3. 精度 30m より悪い測位、時速 32km を超える「飛び」は使わない
4. 止まっているとき（速度がほぼ 0）の揺れは足さない
5. 標高はなめらかにしたうえで、5m 以上の変化だけを上り下りに数える

合成データ（街中の周回コース、誤差 4〜8m、GPS の飛び、信号待ちなど 7 パターン × 10 回）での平均誤差は **約 1%**（最大 2.6%）です。
`node tests/accuracy.mjs` で確認できます。

## ブラウザ版の使い方
位置情報は HTTPS のページでしか使えないため、どこかに置く必要があります。
**公開範囲に注意**: 置いた URL を知っている人は誰でもアプリを開けます（記録は各自の端末に保存されるので、他人の記録が見えることはありません）。

1. このフォルダ（`native/` と `tests/` は不要）を HTTPS で配信する
2. iPhone の Safari で開く → 共有 → **ホーム画面に追加**
3. 初回スタート時に位置情報を **許可**

**ブラウザ版の制限**: 画面ロック中・他のアプリを表示中は GPS が止まります（iOS の仕様）。計測中は画面をつけたままにしてください（自動でスリープを防ぎます）。
古い iOS などでスリープ防止が効かないときは、計測画面に案内が出ます。その場合は 設定 → 画面表示と明るさ → 自動ロック を「なし」にしてから走ってください。
途切れた区間は直線で補い、記録の詳細に「GPS が途切れた区間」として表示します。

## 開発者向け
ビルド不要の静的ファイルです（ES Modules）。

```sh
python3 -m http.server 8765         # http://localhost:8765/ で開く（localhost なら位置情報も使えます）
node --test tests/*.test.mjs        # 計算ロジックのテスト（GPS・ワークアウト・集計・GPX・import の整合）
node tests/sw-check.mjs             # sw.js のファイル一覧の確認
node tests/accuracy.mjs             # 距離精度の比較
node tests/e2e.mjs shots            # 画面の通しテスト（Playwright、合成 GPS で 5km 走る）
node tests/e2e-interval.mjs shots   # インターバルの通しテスト
```

| ファイル | 役割 |
|---|---|
| `js/geo.js` | GPS 計測の中心（カルマンフィルタ、距離、ラップ、自動一時停止、標高、ベストエフォート） |
| `js/workout.js` | 目標走・インターバルの進行と音声ガイド |
| `js/stats.js` | 週・月の集計、自己ベスト、予想タイム、連続記録 |
| `js/store.js` | 保存（IndexedDB）、GPX 入出力、バックアップ |
| `js/platform.js` | ブラウザ版とネイティブ版の差（GPS・音声） |
| `js/app.js` | 画面とイベント |
| `js/charts.js` / `js/map.js` / `js/share.js` | グラフ・地図・共有画像 |
| `sw.js` | オフライン起動用キャッシュ。**ファイルを更新したら `CACHE` の番号を上げる**（全ファイルがそろってから新しい版に切り替わります） |

テストで使う GPS データはすべて合成データ（東京駅付近を原点にした架空のコース）です。
